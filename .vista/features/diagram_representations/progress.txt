1. **ClaudeProvider's get_invocation() outputs stream-json, not plain text:**
   - provider_service.py:134,141 includes `--output-format=stream-json`
   - This format is designed for loop output parsing (parsed by OutputParser)
   - Chat service cannot use get_invocation() directly — output would be JSON lines
   - Decision: Chat builds its own CLI command using `claude -p --model {model}`
